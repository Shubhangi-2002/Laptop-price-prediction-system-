# Laptop-price-prediction-system-
A Machine Learning-based web application that predicts laptop prices based on various features such as brand, RAM, processor, storage, and more.

#Project Overview
This project uses regression techniques to estimate laptop prices accurately. It involves end-to-end ML workflow including data preprocessing, model training, and deployment using Streamlit for real-time predictions.

#Tech Stack
Programming Language: Python
Libraries: Scikit-learn, Pandas, NumPy
Visualization: Matplotlib, Seaborn
Deployment: Streamlit

#Features
Data Cleaning & Preprocessing
Feature Engineering
Regression Model Training
Achieved 88% Accuracy
Real-time price prediction via web interface

#Model Details
Algorithm Used: Regression Model (e.g., Linear Regression / Random Forest)

#Input Features:
Brand
RAM
Processor
Storage
GPU
Display Specs

#Output:
Predicted Laptop Price


#Results

Model Accuracy: 88%
Provides fast and reliable predictions
User-friendly UI for easy interaction
